# 📰 Pravdorub

**Telegram‑бот для проверки достоверности новостей и выявления фейков**

Ассистент, который анализирует текст на предмет дезинформации, проверяет числовые данные, парсит статьи по ссылкам и даёт рекомендации по доверию к информации.

---

## 🎯 Основные возможности

- **🔍 Анализ текста** — проверка новостей и утверждений на достоверность с использованием веб‑поиска и нейросетевых моделей
- **🔗 Парсинг ссылок** — извлечение основного содержания статей из URL (Trafilatura + BeautifulSoup) без шума боковых колонок
- **📊 Проверка чисел** — строгие правила для числовых данных (возраст, суммы, проценты). Если расхождение >3%, бот не выдаст "ФАКТ"
- **🤖 Несколько моделей** — три независимых версии бота с разными API (Perplexity, Ollama, ProxyAPI+GPT)
- **📝 Логирование** — сохранение user_id в анонимизированном виде (SHA‑256 хеш)
- **⚠️ Прозрачность** — честный рассказ об ограничениях моделей и галлюцинациях ссылок

## 🛠️ Технологический стек

- **Python 3.9+** — основной язык программирования
- **python-telegram-bot** — работа с Telegram Bot API
- **OpenAI API** (Perplexity, ProxyAPI) — нейросетевые модели с веб‑поиском
- **Ollama** — локальная нейросеть (Llama 2) для офлайн‑анализа
- **Trafilatura** — извлечение основного текста из веб‑страниц
- **BeautifulSoup 4** — HTML‑парсинг (fallback для Trafilatura)
- **aiohttp** — асинхронные HTTP‑запросы
- **python-dotenv** — управление переменными окружения

⚠️ Важные ограничения
Галлюцинации ссылок
Даже с веб‑поиском нейросетевые модели могут:

выдавать несуществующие URL

ссылаться на страницы с ошибкой 404

приписывать источникам информацию, которую они не содержат

Это известное ограничение LLM. Часть проекта — показать, почему автоматическому факт‑чеку нельзя полностью доверять без человеческой верификации.

Персональные данные
Бот может получить user_id и имя пользователя из Telegram, но в логах хранит только SHA‑256 хеш без ФИО и никнейма.

Зависимость от API
Основная версия (bot3.py) требует активные API ключи (ProxyAPI/OpenAI). Локальная версия с Ollama работает без интернета, но менее мощная.

💡 Основная идея
Показать, как нейросетевые модели и веб‑технологии могут помочь в борьбе с дезинформацией, но при этом честно рассказать об их ограничениях и необходимости человеческой верификации.

Дезинформация — реальная проблема цифровой эпохи, и Pravdorub демонстрирует, как технология может быть частью решения (но не полным решением).
