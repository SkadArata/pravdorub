## 🛠️ Технологический стек

- **Python 3.9+** — основной язык программирования
- **python-telegram-bot** — работа с Telegram Bot API
- **OpenAI API** (Perplexity, ProxyAPI) — нейросетевые модели с веб‑поиском
- **Ollama** — локальная нейросеть (Llama 2) для офлайн‑анализа
- **Trafilatura** — извлечение основного текста из веб‑страниц
- **BeautifulSoup 4** — HTML‑парсинг (fallback для Trafilatura)
- **aiohttp** — асинхронные HTTP‑запросы
- **python-dotenv** — управление переменными окружения
